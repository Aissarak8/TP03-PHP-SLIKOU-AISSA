# TP03 PHP - Suivi des notes des apprenants

- Nom : SLIKOU
- Prénom : AISSA
- Groupe : G3
- Établissement : FSSM

## Objectif

Créer une petite application PHP pour saisir, enregistrer, afficher et analyser les notes des apprenants.

## Parties du TP

- Partie 0 : mise en place du projet
- Partie 1 : variables, constantes, types et chaînes
- Partie 2 : conditions et boucles
- Partie 3 : tableaux, statistiques et tris
- Partie 4 : fichiers inclus et formulaires GET/POST
- Partie 5 : fichiers CSV et JSON
- Partie 6 : cookies, sessions, redirections et dates

## Lancement avec XAMPP

1. Démarrer Apache depuis le panneau XAMPP.
2. Placer le dossier `tp_php` dans le dossier `htdocs` de XAMPP, ou lancer le serveur PHP depuis ce dossier :

```powershell
C:\xampp\php\php.exe -S localhost:8000
```

3. Ouvrir `http://localhost:8000/exo1_bases.php` dans le navigateur.
